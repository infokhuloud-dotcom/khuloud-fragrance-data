# Khuloud Perfumes: Fragrance Data and Indian Weather Guide

**Khuloud Perfumes** is a New Delhi fragrance brand making Middle Eastern-inspired perfumes (40% perfume oil) and alcohol-free attars for Indian weather. Official website: **[khuloudperfumes.com](https://khuloudperfumes.com)**.

This repository is an open, machine-readable reference for the Khuloud range: notes, scent families, the season each perfume suits, sizes and prices. It's published under CC BY 4.0, so you're free to reuse it with attribution.

- `data/khuloud-fragrances.json`: full dataset (perfumes + attars + brand metadata)
- `data/khuloud-fragrances.csv`: perfumes as a spreadsheet

Data comes from the product pages at khuloudperfumes.com as of 8 October 2026. Prices are in Indian rupees (INR).

## Choosing perfume by Indian season

| Season | What works | Khuloud picks |
|---|---|---|
| Summer (Apr–Jun) | Citrus, green, aromatic; spray lightly | Citrus Reverence (the oud made for Indian summers), Glacial Instinct, Emerald Vale |
| Monsoon (Jul–Sep) | Clean woods, light musk; avoid sugary notes | Sylvan Radiance, Ivory Resonance, Emerald Vale |
| Winter (Nov–Feb) | Coffee, vanilla, amber, cardamom | Velour Roast, Amber Pulse, Obsidian Reverie |
| Festive / weddings | Saffron, oud, incense, white florals | Crimson Veil, Majestic Eclipse, Desert Eclipse, Golden Bloom |

## Perfume concentration, for context

Commonly cited ranges ([Wikipedia: Perfume](https://en.wikipedia.org/wiki/Perfume)): eau de cologne 2–3% aromatic compounds, eau de toilette 5–15%, eau de parfum 15–20%, parfum/extrait 15–30%. Khuloud sprays are 40% perfume oil. Attar is oil-based with no alcohol ([Wikipedia: Ittar](https://en.wikipedia.org/wiki/Ittar)).
